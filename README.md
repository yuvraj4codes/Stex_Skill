## 🌟 Overview

**STEX (Student Skill Exchange)** solves a fundamental problem faced by college students: *many students want to learn practical skills, and many peers possess those exact skills, but there is no dedicated, non-monetary platform to connect them.*

STEX turns every student into both a **Learner** and a **Teacher**.

> **"I teach what I know, you teach what you know."**

---

## 🚀 Key Features

* **🎓 Student Profile & Skill Matrix:** Showcase skills you can teach alongside skills you want to learn.
* **🔍 Skill & Student Discovery:** Search for peers by specific skills, course, semester, or availability.
* **🤝 Reciprocal Matching:** Intelligent compatibility scoring to match students with complementary learning goals.
* **💬 1-on-1 Student Chat:** Direct messaging to coordinate peer tutoring sessions and share learning resources.
* **⚡ Project Collaboration Finder:** Post project ideas (e.g., AI Attendance System, Event Management App) and recruit teammates based on required skill sets.
* **📚 Learning Resource Sharing:** Share YouTube tutorials, PDFs, notes, and repositories.
* **🛡️ Built-in Safety & Moderation:** Student reporting, blocking, and account verification options.

| **Backend** | Node.js + Express / Supabase / Firebase |
| **Database** | PostgreSQL / Firebase Firestore |
